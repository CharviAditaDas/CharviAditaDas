🏢   ERMS — Employer Relationship Management System
  
   
Challenge: A university Career Services team needs every coordinator to own their employer relationships privately — while still preventing two people from cold-calling the same company. That means disclosing that a record exists, without disclosing anything inside it.
Pillar	Deliverable
Data Layer	23 PostgreSQL tables, ~50 row-level security policies
Access Model	Scoped ownership — 150 employers per coordinator, enforced by database trigger
Disclosure	Shared directory exposes employer names only; a function signature is the privacy boundary
Workflow	Ownership transfers, bulk CSV import, append-only audit log
Assurance	149 security assertions covering IDOR, privilege escalation and data leakage
Why it stands out: authorization lives in PostgreSQL, not in the app code. The page that displays an employer contains no ownership check at all — if the record belongs to a colleague, the query simply returns nothing.
